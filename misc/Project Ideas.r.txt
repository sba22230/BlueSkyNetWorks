# 🔍 **WHAT’S MISSING IN THE PROJECT? (High‑Value Additions)**

These are *not* required for correctness, but they would significantly deepen the analysis of #speirgorm.

## **1. Temporal Network Analysis (TSNA) — but with animation**
You already build a `networkDynamic`, but you don’t:

- compute temporal betweenness  
- compute temporal reachability  
- animate the network over time  

These are the core strengths of `tsna` and `ndtv`.

## **2. Influence propagation modelling**
For a hashtag community, you can model:

- cascade depth  
- cascade breadth  
- reproduction number \( R_t \) of reposts  
- influence decay curves  

## **3. Topic modelling on post text**
You already ingest text but don’t analyse it.

Suggested additions:

- `stm` or `text2vec` topic models  
- sentiment over time  
- cluster communities by linguistic similarity  

## **4. Bot / automation detection**
Useful for social network integrity:

- posting frequency entropy  
- repost/like ratio anomalies  
- temporal burstiness  

## **5. Structural holes & brokerage**
Use:

- Burt’s constraint  
- effective size  
- bridging centrality  

These identify “connectors” between communities.

## **6. Edge weighting by engagement**
Currently edges are unweighted except for repost_count.

You could weight edges by:

- like_count  
- reply_count  
- bookmark_count  
- time‑decay weighting  

## **7. Robustness / attack simulations**
Simulate:

- node removal  
- edge removal  
- targeted vs random attacks  

This reveals network resilience.
