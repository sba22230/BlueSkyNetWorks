You’re doing something very sensible here: **comparing statnet and igraph metrics side‑by‑side** is one of the best ways to understand how each library conceptualises the network. The challenge is that:

- igraph returns vectors keyed by vertex name  
- statnet returns vectors keyed by vertex ID  
- some metrics exist in one package but not the other  
- some metrics use different definitions (e.g., closeness, betweenness normalisation)

What you want is a **single tidy table** that:

- lists each metric  
- shows the igraph value  
- shows the statnet value  
- highlights differences  
- can be printed, saved, or visualised  

Below is a clean, robust, non‑breaking method that fits directly into your existing `4_ComputeMetrics.R` workflow.

---

# ⭐ **Unified Comparison Table for igraph vs statnet**

### Step 1 — Create a helper that aligns vectors by node name

```r
align_metric <- function(igraph_vec, statnet_vec, nodes) {
  tibble(
    name = nodes$name,
    igraph = igraph_vec[match(nodes$name, names(igraph_vec))],
    statnet = statnet_vec[match(nodes$name, names(statnet_vec))]
  )
}
```

This ensures both packages’ metrics line up correctly.

---

# ⭐ Step 2 — Build a combined comparison table

Add this block **after** you compute all metrics in `4_ComputeMetrics.R`:

```r
comparison_list <- list(
  degree_in = align_metric(
    igraph::degree(g_igraph, mode = "in"),
    degree(bluSkynet, cmode = "indegree"),
    nodes
  ),
  degree_out = align_metric(
    igraph::degree(g_igraph, mode = "out"),
    degree(bluSkynet, cmode = "outdegree"),
    nodes
  ),
  betweenness = align_metric(
    betweenness_ig,
    betweenness(bluSkynet, gmode = "digraph"),
    nodes
  ),
  closeness = align_metric(
    closeness(g_igraph, mode = "out"),
    closeness(bluSkynet, cmode = "suminvdir"),
    nodes
  ),
  pagerank = align_metric(
    pagerank_vals,
    rep(NA, nrow(nodes)),   # statnet has no PageRank
    nodes
  ),
  eigenvector = align_metric(
    eigen_vals,
    evcent(bluSkynet, gmode = "digraph"),
    nodes
  )
)
```

---

# ⭐ Step 3 — Combine into one long table

```r
comparison_df <- bind_rows(
  lapply(names(comparison_list), function(metric) {
    comparison_list[[metric]] %>%
      mutate(metric = metric)
  }),
  .id = "metric_group"
) %>%
  select(metric, name, igraph, statnet)
```

This produces a tidy table:

| metric        | name        | igraph | statnet |
